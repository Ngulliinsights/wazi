# Wazi

Open-contracting agent backend for Kenyan public procurement.

## Documentation

See [docs/README.md](docs/README.md) for full documentation, including:
- Installation and usage
- Architecture
- API reference
- Strategic direction (ADR 001)

## Quick Start

```bash
python run.py
```

This creates a virtual environment, installs dependencies, loads sample data, and starts the UI at http://127.0.0.1:8000.
