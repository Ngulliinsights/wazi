# WAZI: brand and visual language

**wazi** (Kiswahili, adjective, say *WAH-zee*): open · transparent · clear · plain.

WAZI turns Kenya's open contracting data into a short, sourced brief on a closed public tender. It runs 14 systematic checks and shows every source. A named person decides — the tool never awards, advises to bid, or issues a verdict.

---

## 1. Positioning

| | |
|---|---|
| **Promise** | Public tenders, made wazi. |
| **Secondary line** | *Zabuni wazi*: open tenders, in plain sight. (Have a native Kiswahili speaker confirm before public use.) |
| **For** | Procurement officers and evaluation committees; small suppliers (including AGPO youth, women and persons-with-disabilities firms); auditors, journalists and citizens. |
| **Role** | An evidence engine that runs 14 systematic checks and shows every source. Not a judge, not an investigator, not a verdict. |
| **Built on** | Kenya's open contracting data (OCDS). Built for the Bid Box Challenge. |

### Values

1. **Open.** Sources first. Nothing hidden, nothing assumed.
2. **Plain.** Words anyone can read, numbers anyone can check.
3. **Accountable.** A named person decides, never the tool.
4. **Careful.** A signal is worth a look, never proof.
5. **Rigorous.** 14 systematic checks, every run. Same depth, no fatigue.

---

## 2. Name

- **WAZI** in the wordmark and headings. **Wazi** in running text.
- Never "WAZI AI". The product is a tool that prepares briefs; say so.
- Descriptor when needed: *WAZI: tender briefs*.
- Credit line: *Built for the Bid Box Challenge.*
- Not yet checked: trademark, domain names and social handles.

---

## 3. Voice and tone

**Plain** (short sentences, no jargon). **Calm** (never alarmed, never accusing). **Specific** (the number, the source, the date). **Humble** (say what was not checked). English first; Kiswahili only after a native speaker has reviewed it.

| Say | Don't say |
|---|---|
| Worth a look, not proof | Red flag. Suspicious. |
| Not recorded in the notice | Missing or invalid data |
| This tender is still open, so WAZI will not work on it. | Error 403: forbidden |
| Most were between 28 and 36 days | 25th to 75th percentile |
| A named person decides. | AI-powered decisions |
| No comparable past awards were found. | Benchmark failed |
| The brief shows 14 checks and their sources. | The tool analysed and ranked the tender. |

**Never** use: corrupt, rigged, fraud, bribe, illegal, "should bid", "best bidder", or any word that sounds like a verdict. The product refuses questions that ask for them, and its copy should too.

**Microcopy:** loading *"Reading the record..."* · empty *"Pick a tender to begin."* · done *"Ready for your review."* · replay *"Replay: read as of 2025-05-01. Not a live opportunity."*

**Lockups:** horizontal (symbol left of wordmark) and stacked (symbol above wordmark).
**Reversed:** on Msitu green use white strokes with a pale-mint dot (`#BFE3D3`); on ink use `#F6F5F1` strokes with a `#4FB890` dot.
**App icon and favicon:** the symbol, white on a Msitu green rounded square (corner radius about 25%), with a slightly heavier stroke (7) below 32 px.
**Size and space:** symbol at least 16 px, wordmark at least 72 px. Clear space equals the dot's width on every side.

**Never:** use flag colours or national emblems (WAZI is non-partisan); put red or amber on the mark; stretch, outline, add gradients or shadows; recolour the dot.

## 5. Colour

Names are Kiswahili for the thing the colour recalls.

| Name | Meaning | Hex | Use |
|---|---|---|---|
| **Msitu** | forest | `#1F6F55` | Brand, primary actions, "verified" |
| **Wino** | ink | `#1D2320` | All text |
| **Mchanga** | sand | `#F6F5F1` (+ white cards) | Page ground and surfaces |
| **Jua** | sun | `#8A5A00` on `#FBF3DF` | **Signals only**: worth a look, not proof |
| **Ziwa** | lake | `#1E5A8A` on `#E4EEF6` | Information: replay notices, links |
| **Hatari** | danger | `#9B2C2C` | **Errors only.** Never a signal, never an accusation |

**Dark mode:** ground `#141816`, ink `#E8ECE9`, Msitu `#4FB890` on `#1B2D27`, Jua `#E0B04A` on `#2C2615`, Hatari `#E07A7A`. Dark Ziwa is **proposed** (`#7DB4E5` on `#14202B`) and not yet contrast-checked.

**Rules**
1. **Colour never carries meaning alone.** A signal is amber *and* says "worth a look, not proof". A replay is blue *and* says it is a replay.
2. Amber is only for signals. Red is only for errors. Nothing about a supplier, buyer or officer is ever red.
3. Text pairs are chosen for WCAG AA (4.5:1). Confirm with a contrast checker before release.

## 6. Typography

| Use | Face | Notes |
|---|---|---|
| Headings, wordmark text | **Plus Jakarta Sans** 800 / 700 | Open-licence font: confirm the licence and **self-host** it so the app stays fast on weak connections |
| Body, tables, data | System font stack | Nothing extra to download |
| Money and counts | Body face with **tabular figures** | `font-variant-numeric: tabular-nums` |

**Scale (px):** 46 display · 30 title · 22 section · 16 body · 12.5 caption. Body line height 1.55. Keep line length under about 70 characters.

---

## 7. Graphic language

- **Shapes:** rounded rectangles (radius 10 to 16), one open frame as the recurring motif.
- **Lines:** 1 px hairlines in `#D9D6CC`; icons are outline, round-capped, 2 px.
- **Imagery:** none decorative. The brief is the visual. No photos of officials, no maps that imply a place is at fault.
- **Motion:** minimal and respectful of reduced-motion settings.

---

## 8. Applying it to the app

Design tokens (light, then dark). `--info` and `--infobg` are new; the rest replace the current values one for one.

```css
:root{
  --bg:#F6F5F1; --fg:#1D2320; --mut:#5B655F; --card:#fff; --line:#D9D6CC;
  --acc:#1F6F55; --accbg:#E6F2ED;
  --warn:#8A5A00; --warnbg:#FBF3DF;      /* signals only */
  --info:#1E5A8A; --infobg:#E4EEF6;      /* replay, links */
  --bad:#9B2C2C;                         /* errors only */
}
@media (prefers-color-scheme:dark){:root{
  --bg:#141816; --fg:#E8ECE9; --mut:#9AA59F; --card:#1C211F; --line:#2E3532;
  --acc:#4FB890; --accbg:#1B2D27; --warn:#E0B04A; --warnbg:#2C2615;
  --info:#7DB4E5; --infobg:#14202B;      /* proposed */
  --bad:#E07A7A;
}}
```

| Element | Treatment |
|---|---|
| Header | Horizontal lockup, then the tagline in `--mut` |
| "Draft: not an award decision" | Neutral outline chip, always visible |
| **Replay banner** | **`--infobg` / `--info`** (not amber): it explains the reference date |
| Signal chip | `--warnbg` / `--warn`, text "worth a look, not proof" |
| **In short** card | `--accbg` with a `--acc` border, first thing under the glance table |
| Errors and refusals | `--bad` text with a plain-language explanation |
| Primary action | `--acc` fill, white text, minimum 44 px high |
| Reject | Outline in `--bad` (it is destructive, not an accusation) |
| Fingerprint | Monospace, first 12 characters, with a copy button |
| Focus | 3 px ring in `--acc` |

**Accessibility:** AA contrast, 44 px touch targets, visible focus, labelled controls, live regions for progress, reduced-motion respected, no meaning carried by colour alone, print stylesheet for the brief.
